Політика конфіденційності єСвітло для Android

ЄСвітло показує графіки відключень електроенергії та повідомлення операторів. Для використання застосунку обліковий запис не потрібен.

Дані на пристрої

Назви локацій, обрані регіони й черги, налаштування та кеш графіків зберігаються на пристрої. Системна геолокація не використовується. Ви можете видалити локації в застосунку або очистити всі локальні дані в налаштуваннях Android.

Запити до API

Застосунок запитує графіки за кодом регіону через HTTPS. Сервер обробляє IP-адресу для обмеження частоти запитів. Лічильники на сервері застосунку зберігаються в оперативній пам’яті та очищаються в наступному хвилинному вікні.

Адресний пошук є добровільним. За вашим запитом застосунок передає регіон, населений пункт, вулицю й номер будинку серверу єСвітло через HTTPS для перевірки у сервісі оператора. Збережену адресу локації можна змінити або видалити на пристрої. Під час разової перевірки сервер не зберігає адресу.

Якщо ввімкнути сповіщення про аварії за адресою, сервер зберігає адресу, технічний ідентифікатор підписки та токен Firebase для перевірок і доставки сповіщень. Ім'я локації залишається на пристрої. Після вимкнення сповіщень або видалення локації ці дані видаляються із сервера під час найближчої синхронізації. Без поновлення підписка спливає через 30 днів. Публічні журнали та API адреси підписників не показують.

Сповіщення

Для доставки сповіщень використовується Google Firebase Cloud Messaging. Firebase обробляє ідентифікатор інсталяції, реєстраційний токен і технічні відомості про застосунок. Якщо ви ввімкнули сповіщення, Firebase також обробляє підписки на теми з кодами вибраних регіонів і черг. Вимкнення сповіщень у застосунку скасовує підписки після синхронізації. Дані інсталяції зберігаються відповідно до правил Firebase.

Конфіденційність у Firebase

Збірка з GitHub та зовнішні посилання

Збірка з GitHub запитує інформацію про релізи через GitHub API. Якщо ви відкриваєте зовнішнє посилання на сайт оператора, GitHub або Telegram, відповідний сервіс обробляє дані за власними правилами.
