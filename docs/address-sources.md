# Джерела для пошуку черги за адресою

## Поточні аварії за адресою

- [ДТЕК Одеса](https://www.dtek-oem.com.ua/ua/shutdowns). Відповідь форми містить тип, причину, початок та очікуване відновлення. 23 листопада перевірено, що тип `2` використовується також для стабілізаційних відключень. Аварійний статус вимагає явно аварійної або екстреної причини.
- [Хмельницькобленерго](https://hoe.com.ua/shutdown/new). Перевірено активну аварію з початком і прогнозом відновлення та окрему відповідь без зареєстрованого відключення. Рядки погодинного графіка можуть теж мати тип «Аварійне». Перевірка враховує вид робіт у першій колонці.
- [Львівобленерго](https://poweron.loe.lviv.ua/). Перевірено активне відключення за номером будинку, час початку й прогноз. Ідентичні дублікати запису об'єднуються.
- [Житомиробленерго](https://ztoe-poweron.inneti.net/). Перевірено активне відключення за конкретним будинком та фільтрацію за видом робіт. Для однойменних населених пунктів укажіть РЕМ у дужках, як у каталозі оператора.
- [Черкасиобленерго](https://www.cherkasyoblenergo.com/off). Доступний публічний адресний режим із фільтром «Аварійні». Інтеграцію ще не перевірено.
- [Миколаївобленерго](https://off.energy.mk.ua/). Сервіс відокремлює приналежність адреси до черг від застосування ГАВ або СГАВ. Локальну аварію та строк її усунення для будинку не підтверджено.

Перевірено 21 листопада 2026 року за 24 записами каталогу єСвітло. В адресному API підключено Одесу й область, ЦЕК і Миколаївську область. Для решти операторів доступний ручний вибір. Дніпропетровщина має окремі записи для ДТЕК і ЦЕК. [Перелік сторінок операторів від Держенергонагляду](https://sies.gov.ua/zvernennya-gromadyan/najbilsh-zapituvana-informaciya/grafiki-vidklyuchen-elektropostachannya-operatoriv-sistemi-rozpodilu)

Для застосунку й Telegram-бота достатньо одного серверного сервісу пошуку в репозиторії сайту. Показувати пропозицію можна після точного збігу адреси та перевірки, що знайдена підчерга є в каталозі графіків оператора. Кілька підчерг слід показувати як варіанти для підтвердження. Якщо дані недоступні, застарілі або неоднозначні, залишити ручний вибір. Для нагадувань достатньо зберігати назву локації, регіон, підтверджену підчергу та інтервал нагадування.
